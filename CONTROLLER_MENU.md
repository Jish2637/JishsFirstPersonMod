# Menu controls — ReSkate 2.1.0 compatibility test

Insert opens the stock menu and companion panel. F9 hides/shows the companion inside the stock menu; it does not open a standalone panel.

Use mouse and keyboard in the companion. ReSkate owns controller menu navigation. Controller shortcuts for opening the companion remain disabled.

Click Record beside a supported gameplay binding, release all controller buttons, hold the desired chord, then release it to save. During recording in the focused companion, verified stock menu readers receive neutral input. The mod reads the physical chord independently. Stock navigation resumes when recording finishes, is cancelled, the panel closes or focus is lost. Startup fails closed if the native readers do not verify.

Controller and Steam Input combinations need in-game confirmation. See docs/COMPATIBILITY_210_TEST_REPORT.md.
