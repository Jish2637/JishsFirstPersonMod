# Installation — 1.36.2 for ReSkate 2.1.1

Close Skate and extract JishsFirstPersonMod-1.36.2-reskate-2.1.1.zip beside Skate.exe and ReSkateLauncher.exe, merging Mods and scripts. Enable Jish’s First Person Mod in the launcher. Settings and personal presets are preserved.

Open Insert → Skater → First Person. Native head movement is in Advanced → On-foot right stick look. It defaults off and changes camera feel; see its hover text. The separate test INI is no longer used.

If you already have the updater, download the update through Mod updates, choose Install after I close Skate, close Skate normally and wait for the completion message. Restart ReSkate yourself.
