## Installation

Close Skate. Extract `JishsFirstPersonMod-1.35.0-reskate-2.1.1.zip` into the ReSkate folder beside `Skate.exe` and `ReSkateLauncher.exe`, merging `Mods` and `scripts` and replacing this mod’s existing files. Enable **Jish’s First Person Mod** in the launcher.

Open **Insert → Skater → First Person**.

Existing settings and personal presets are preserved. **Reapply your preferred preset after updating.** Load **Jish’s Recommended** to use the updated recommended settings.

Requires official ReSkate 2.1.1.
