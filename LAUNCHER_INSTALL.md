## Installation

Close Skate. Extract `JishsFirstPersonMod-1.36.0-reskate-2.1.1.zip` into the ReSkate folder beside `Skate.exe` and `ReSkateLauncher.exe`, merging `Mods` and `scripts` and replacing this mod’s existing files. Enable **Jish’s First Person Mod** in the launcher.

Open **Insert → Skater → First Person**.

Existing settings and personal presets are preserved.

Requires official ReSkate 2.1.1.

For future mod updates, open **Mod updates**, download the update and choose **Install after I close Skate**. Close Skate normally and wait for the completion message before starting ReSkate yourself.
