# Jish’s First Person Mod 1.35.0 — ReSkate 2.1.1

## Updates

- Updated for ReSkate 2.1.1.
- Mod settings are now inside **Insert → Skater → First Person**, with stock controller, mouse and keyboard navigation.
- Includes presets, binding recording and the existing camera options in the embedded menu. The separate panel and its F9 shortcut have been removed.
- Fixed First Person controller toggle combinations triggering emotes. Glance double-tap emote behavior remains available.
- Removed MSC `[FP]` nametag reporting.
- Updated **Jish’s Recommended**: on-foot right-stick smoothing disabled and on-board right-stick look enabled, alongside the updated glance and recovery settings.

## Installation

Close Skate. Extract `JishsFirstPersonMod-1.35.0-reskate-2.1.1.zip` into the ReSkate folder beside `Skate.exe` and `ReSkateLauncher.exe`, merging `Mods` and `scripts` and replacing this mod’s existing files. Enable **Jish’s First Person Mod** in the launcher.

Open **Insert → Skater → First Person**.

Existing settings and personal presets are preserved. **Reapply your preferred preset after updating.** Load **Jish’s Recommended** to use the updated recommended settings.

Requires official ReSkate 2.1.1.
