# Mod updater

Open Insert → Skater → First Person → Mod updates. Automatic checking is optional and runs once per launch. Download and installation always require your choice. After downloading, choose Install after I close Skate, close Skate normally, and wait for completion before restarting yourself.

Requires official ReSkate 2.1.1, the standard scripts/Custom installation layout and this mod’s supported dinput8 loader. No ReSkate updates, game restarts or server messages are performed. Existing settings, personal presets and logs are preserved. Downloads and backups are in scripts/Custom/FirstPerson/updates.

The updater test builds were user-confirmed working before release. Automated validation is recorded in the release validation report. Historical test documents describe the earlier test packages, not installation instructions for this release.
